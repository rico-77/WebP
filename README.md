# Blue Barricade — Website

Professional static landing page for Blue Barricade, a security consultancy.

## Files

- `index.html` — website structure and content
- `style.css` — responsive visual design
- `README.md` — deployment notes

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, e.g. `blue-barricade`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. GitHub will publish the site at:
   `https://YOUR-USERNAME.github.io/blue-barricade/`

GitHub Pages automatically republishes when you push changes to the selected branch.

## Before publishing

Replace:
- `contact@bluebarricade.com` with your real business email.
- Any service wording you want to change.
- The year if necessary.

Do not put passwords, API keys, private client information, or other secrets in this repository.
